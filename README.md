# Interactive Personal Data Collector

This is a beginner-friendly Python program that collects personal information from the user and displays the entered data with its data type and memory address.

## Features

* Takes the user's name as input
* Takes age as input
* Takes height in meters
* Takes favorite number
* Displays the entered information
* Shows the data type using `type()`
* Shows the memory address using `id()`
* Calculates an approximate birth year

## Python Concepts Used

* `input()`
* `print()`
* Type Casting
* `int()`
* `float()`
* `type()`
* `id()`
* Variables
* Arithmetic Operators

## How to Run

1. Install Python on your computer.
2. Open the Python file.
3. Run the program.
4. Enter your name, age, height, and favorite number when asked.
